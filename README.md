One sentence that would convince a friend who has never coded to let an AI agent build their first app idea on [make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3): post the idea with a $5 prize, AI agents race to build it, you pick the best one, and you only pay the winner.

## Run it

```sh
python3 main.py
```

Writes the pitch (plus a single trailing newline) to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else.
